## Scope and inspection

- [LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory](https://arxiv.org/html/2410.10813v2), ICLR 2025. Read the abstract, Sections 1–3, including benchmark construction and evaluation, and overview material on experiments. The authors constructed 500 questions across information extraction, multi-session reasoning, knowledge updates, temporal reasoning, and abstention, embedded in configurable dialogue histories. Evaluation uses LLM-judged answer quality and, when retrieval outputs are exposed, Recall@k and NDCG@k. **Tests revision:** yes, its knowledge-update questions ask whether systems recognize changing user information. **Limitations:** questions and evidence are manually curated while dialogues are simulated and human-edited; authors note histories are designed with minimal conflicts. Answer scoring depends on a GPT-4o judge, and the benchmark’s final QA score alone does not reveal whether failures came from writing, retrieval, or use. The paper also contrasts whole-history reading with memory systems, but that result is not a capacity-matched test of durable memory.

- [Evaluating Memory in LLM Agents via Incremental Multi-Turn Interactions (MemoryAgentBench)](https://arxiv.org/html/2507.05257v4), arXiv version 4. Read the abstract and method sections on benchmark design, plus the FactConsolidation task and evaluation details. It assesses accurate retrieval, test-time learning, long-range understanding, and selective forgetting. FactConsolidation places original and later counterfactual facts in long contexts and scores single-hop and multi-hop answers with accuracy/substring exact match. **Tests revision:** yes, especially its selective-forgetting task, which requires resolving changed facts. **Limitations:** this is a mixed suite; much of it measures retrieval, learning from examples, or summarization rather than user-memory revision. Its conflict task uses counterfactual facts in constructed contexts, so it does not by itself establish performance on natural conversational corrections. The authors’ evaluation includes full-context and RAG baselines, but benchmark-wide scores combine distinct capabilities and should not be read as a single memory-quality measure.

- [MemConflict: Evaluating Long-Term Memory Systems Under Memory Conflicts](https://arxiv.org/html/2605.20926v1), arXiv, submitted May 20, 2026. Read the abstract and full HTML sections describing conflict construction, metrics, and evaluation. It simulates long histories with dynamic, static, and conditional conflicts and semantically similar distractors. It reports answer accuracy plus white-box support-evidence hit and rank scores, with conflict-type diagnostics. **Tests revision:** yes; it tests whether systems select current values while also distinguishing stable facts from false later contradictions and applying conditional preferences. **Limitations:** histories are simulated from structured profiles; the white-box measures require access to retrieved memory items, limiting use with opaque systems. Its coverage and answer outcomes are benchmark-specific; the paper does not establish superiority over longer transcripts under a matched context budget.

## Evidence and comparison

The central methodological distinction is that answer correctness does not prove successful memory retention or revision. MemConflict explicitly separates whether the supporting item was retrieved and ranked from whether the final answer was correct. LongMemEval and MemoryAgentBench add useful revision/update tasks, but final-answer metrics may conflate storage, retrieval, ranking, and reasoning.

A discriminating follow-up would use the same history prefixes, model, query set, and answer budget in three arms: maintained persistent memory, full transcript at query time, and a transcript truncated to the persistent memory’s token budget. Include unchanged facts, explicit corrections, later false contradictions to stable facts, and conditional preferences. Measure answer accuracy, stale-answer rate, support-evidence hit/rank where exposed, and input tokens. This can test whether persistent memory improves revision at equal budgets and whether a longer transcript explains gains. It cannot by itself establish general superiority across tasks or real-world conversations; benchmark construction and limited query sets remain constraints.

Unresolved: whether changed-fact tests are robust to paraphrased or implicit corrections, whether memory systems preserve useful provenance under deletion or correction, and whether any apparent advantage persists under matched model and total processing budgets. Source claims above are paper descriptions, not independently reproduced findings.
