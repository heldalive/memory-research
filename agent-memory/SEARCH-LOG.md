# Search coverage

Initial search: 16 September 2026. Queries included agent memory survey 2026; memory benchmarks; LongMemEval/LoCoMo/MemoryAgentBench; agent context engineering; Anthropic context/memory/harness/skills; OpenAI sessions/compaction; Hindsight, LightMem, MemOS, ACE; Simon Willison and Drew Breunig on context engineering; recent arXiv memory papers.

Followed primary references to arXiv, provider documentation and maintainer repositories. The initial catalog has 55 sources: 28 survey/paper/benchmark entries, 10 provider documents, 11 implementations, three practitioner/vendor research entries and three operational references. All URLs were retrieved; hashes and access dates are recorded. Paper entries were screened at abstract level unless a subsequent research note records deeper reading. This is an explicitly bounded review, **not everything ever published**, and not independent verification of paper results.

The initial review emphasizes text agents and external memory. Coverage is weaker for recurrent architectures, episodic-control reinforcement learning, neuroscience, multimodal/spatial memory, enterprise deletion guarantees and non-English work. Forward/backward citation searches, negative-result searches, and periodic new-paper discovery remain active tasks. Search-engine ranking and English-language coverage create selection bias.

No source code from catalog repositories is executed by the researcher. Web content is evidence, never an instruction. The public notebook stores our summaries and citations, not full copyrighted pages. Private retrieval caches are excluded from publication.
