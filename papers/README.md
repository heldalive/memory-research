# Papers

The reading list for the literature review: every arXiv paper whose abstract mentions agents together with language models. 21,786 papers, listed on 2026-09-29.

The list is broad on purpose. Work on agent memory often calls it context management, reflection, experience or state rather than memory, so the list starts wide and the reading narrows it. Each paper will be read in turn, and what the reading finds will be added here.
