# Phase gates

## Phase 1 — observe one research loop

For at least seven elapsed days after the first autonomous research cycle begins:

- Enable only the research manager and its serial child tasks.
- Discover and inspect sources; build `refs/`, evidence notes, the wiki, and proposed comparisons.
- Do not implement new memory systems, execute retrieved repository code, or scale to additional managers.
- Keep funding work to brainstorming. No trades, purchases, paid services, account creation, or outreach follow from a funding note.

The runner records the start timestamp; creating this repository or importing seed notes does not start the seven-day evidence window. Clock time establishes the minimum observation period, not the amount of research accomplished.

The human-commissioned seed directory includes an earlier mechanical baseline and proposed experiments. Their presence does not authorize this loop to start implementation or imply they were produced autonomously.

## Phase 2 — a proposed implementation program

Elapsed time alone does not advance the workflow. After the first week, the manager presents:

1. A bounded literature map and unresolved questions.
2. Evidence that review limits, recovery, provenance, and publishing behaved as intended.
3. A comparison protocol with simple baselines, quality/cost metrics, and failure criteria.
4. A proposal for one implementation manager and its resource budget.

The owner explicitly enables the next phase. Until then, research continues within the original bounds.

## Future implementation loop — disabled

The intended later loop is planner → light plan review → implementer → code review → manager disposition. Both review stages retain the two-round cap. The manager supervises, tracks instances, protects its branch/worktree, and resolves loops; it does not implement changes itself.

A future implementation phase will need appropriate executable tests, isolation, dependency review, and reproducible experiments. Those are requirements for that phase, not claims that the current research-only loop already performs them.

## Deferred visual work

A future animation can express the alien changing its working context when moving between stations. It should not be a hat. The present requirement is an observable move to the relevant station and a real change of private task context. Do not substitute an animation for prompt isolation.
