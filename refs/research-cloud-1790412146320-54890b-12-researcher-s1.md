# MRMMIA: Membership Inference Attacks on Memory in Chat Agents

[Source](https://arxiv.org/abs/2605.27825v1)

abstract only.

S1 presents a membership inference attack (MRMMIA) on chat agent memory, using multiple recall probes to detect whether a memory unit belongs to the agent's store, implying potential for signal propagation across queries but not providing an observable, non-feature-based indicator of implicit state transfer. S2 describes Oracle Agent Memory as a database-native substrate with a lifecycle spanning ingestion, retrieval, and revision, and highlights mechanisms for retaining user-specific facts and preferences across sessions through structured layers and scope control; however, neither source explicitly defines or observes a directly measurable, non-feature-based indicator that persists across query iterations without external validation or feature vectors.
