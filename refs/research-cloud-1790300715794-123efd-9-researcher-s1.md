# TOKI: A Bitemporal Operator Algebra for Contradiction Resolution in LLM-Agent Persistent Memory

[Source](https://arxiv.org/abs/2606.06240v1)

abstract only.

S2 reports a multi-agent economic simulation where memory-equipped LLM agents maintain stable economic behavior over 26 simulated weeks, with no measurable effect when agents' memory is deleted, suggesting memory contributes to state consistency. The study observes persistent wealth distribution and stable monetary transmission, with a marginal propensity to consume of 3-4% and no significant re-pricing of menu items. S1 introduces a bitemporal operator framework for contradiction resolution in persistent memory, emphasizing provenance and audit row preservation to prevent belief-drift skew and replay inconsistency, but does not report on intermittent input streams or per-interval coherence scores under bounded token budgets. Neither study provides time-series metrics on output token coherence or decay rates under intermittent, perturbed input streams with bounded token budgets as required by the original research objective. The evidence does not support a direct comparison to continuous static baselines in the specified conditions. A feasible subset of conditions with measurable outputs is observed in S2's economic simulation, where memory retention supports long-term state stability without degradation over time. However, no per-interval coherence or decay rate data exists in the provided excerpts to evaluate memory performance under intermittent streams with known perturbations. The findings suggest memory may contribute to state stability, but do not establish superiority over static input baselines in the defined metrics. The absence of time-series coherence or decay data remains a gap in the evidence base for comparative analysis. In S1, memory's role is structural and conflict-resolving, not directly tied to output
