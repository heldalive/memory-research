# Oracle Agent Memory as an Enterprise Memory Substrate for Long-Horizon AI Agents

[Source](https://arxiv.org/abs/2607.13157v1)

abstract only.

Source [S1] describes a memory substrate for long-horizon agents with lifecycle phases including ingestion, retrieval, and revision, and reports on token efficiency, achieving 93.8% accuracy with about 10.7x fewer tokens than flat-history baselines. Source [S2] introduces Voice Memory for speech recognition, using a frozen corrector and score-gated optimizer to reduce word error rate from 8.36% to 7.52%, with no reported retention metrics or token budget constraints under periodic input over multiple update intervals. Neither source provides explicit retention thresholds across 50 update intervals with bounded token budgets as required by the original query.
