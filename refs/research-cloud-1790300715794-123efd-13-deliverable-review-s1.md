# TOKI: A Bitemporal Operator Algebra for Contradiction Resolution in LLM-Agent Persistent Memory

[Source](https://arxiv.org/abs/2606.06240v1)

abstract only.

S1 provides a bitemporal framework for contradiction resolution with provenance and audit row preservation, addressing belief-drift skew but not output token coherence or per-interval decay metrics. S2 demonstrates stable economic behavior over 26 weeks with no measurable impact from memory deletion, showing wealth distribution stability via rho values declining over time, but lacks per-interval coherence scores and does not report on output token-level metrics under intermittent, perturbed input streams. Neither study offers time-series data for decay rates or coherence under bounded token budgets as required by the research goal.
