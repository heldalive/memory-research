# MRMMIA: Membership Inference Attacks on Memory in Chat Agents

[Source](https://arxiv.org/abs/2605.27825v1)

abstract only.

Source S1 discusses membership inference attacks on chat agent memory but does not describe memory retention mechanisms or state persistence duration. Source S2 outlines a layered memory architecture with lifecycle phases including consolidation, retrieval, and revision, but fails to report on the duration of state persistence or confirm the absence of decay under stable, low-variation input. Neither source provides verbatim evidence for the claimed 'no detectable decay' under controlled conditions. The claim remains unsupported and unverified in the current evidence set.
