# MRMMIA: Membership Inference Attacks on Memory in Chat Agents

[Source](https://arxiv.org/abs/2605.27825v1)

abstract only.

Source S1 investigates membership inference attacks on chat agent memory, identifying privacy risks but not evaluating memory under token budgeting or providing metrics on memory state usage. Source S2 describes a persistent KV cache system for multi-agent edge inference, improving efficiency through cache persistence, yet lacks any evaluation framework tied to token budgeting or explicit memory state tracking within a BigBench context. Neither source documents an extension of BigBench with controlled, transparent evaluation of memory-aware agents under token constraints. The evidence does not support the claim of existing open-source tools meeting the specified criteria for memory-aware evaluation under token budgeting and explicit state tracking. The gap remains unaddressed in current data.
