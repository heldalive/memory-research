# MRMMIA: Membership Inference Attacks on Memory in Chat Agents

[Source](https://arxiv.org/abs/2605.27825v1)

abstract only.

Source S1 discusses membership inference attacks on chat agent memory, indicating that memory content can be probed and inferred by adversaries, which implies potential for implicit knowledge exposure but does not describe contextual inference or implicit accumulation mechanisms. Source S2 outlines a layered memory system with lifecycle phases including ingestion, consolidation, and revision, and emphasizes retention of user-specific facts and procedural knowledge across sessions, but does not specify how such knowledge is inferred or accumulated implicitly during multi-turn interactions without explicit prompts or feature vectors. Neither source provides a direct description of contextual inference patterns as required by the research objective.
