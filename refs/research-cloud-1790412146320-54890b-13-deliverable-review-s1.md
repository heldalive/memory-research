# MRMMIA: Membership Inference Attacks on Memory in Chat Agents

[Source](https://arxiv.org/abs/2605.27825v1)

abstract only.

S1 describes membership inference attacks on chat agent memory using multiple recall probes to detect whether a memory unit belongs to the agent's store, implying potential for signal propagation across queries but not providing an observable, non-feature-based indicator of implicit state transfer. S2 outlines a memory lifecycle with retention of user-specific facts and preferences across sessions via structured layers and scope control, but does not define or observe a directly measurable, non-feature-based indicator that persists across query iterations. Neither source explicitly describes such an indicator, even when mechanisms for retention or signal propagation are implied through indirect means. The request for a directly observable, non-feature-based indicator lacks verifiable support in the provided evidence.
