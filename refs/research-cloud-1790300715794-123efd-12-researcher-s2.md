# But How Would AI Agents Run a Town's Economy?

[Source](https://arxiv.org/abs/2609.11108v1)

abstract only.

S2 reports a multi-agent economic simulation where memory-equipped LLM agents maintain stable economic behavior over 26 simulated weeks, showing no measurable impact when memory is deleted, indicating memory contributes to state consistency through persistent wealth distribution and stable monetary transmission. The study observes a marginal propensity to consume of 3-4% and no significant re-pricing of menu items, with wealth distribution stability measured by rho values declining gradually over time. S1 introduces a bitemporal operator framework for contradiction resolution in persistent memory, emphasizing provenance and audit row preservation to prevent belief-drift skew and replay inconsistency, but does not report on output token coherence or state decay over time under intermittent, perturbed input streams with bounded token budgets. Neither study provides per-interval coherence scores or explicit decay rate metrics as requested in the original query. The available evidence does not support comparative analysis with continuous static input baselines due to missing time-series data on state drift and coherence metrics under controlled perturbations.
