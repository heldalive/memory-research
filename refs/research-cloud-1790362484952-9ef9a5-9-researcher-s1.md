S2 outlines a layered memory architecture for long-horizon agents, emphasizing lifecycle phases such as ingestion, consolidation, retrieval, and revision, with explicit mechanisms for scoping memory across users, agents, and threads. It also evaluates memory performance through metrics like evidence retrieval, recall, and latency, suggesting a system-level approach to memory management. S1 addresses privacy concerns in agent memory through membership inference attacks, indicating that memory content can be sensitive and potentially exposed, but does not describe retention mechanisms or persistence duration under stable conditions. No evidence is provided on memory persistence over time under low-variation inputs.
