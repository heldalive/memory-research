# MRMMIA: Membership Inference Attacks on Memory in Chat Agents

[Source](https://arxiv.org/abs/2605.27825v1)

abstract only.

The excerpts from [S1] and [S2] discuss privacy risks and memory system design for long-horizon agents, respectively, but neither reports explicit memory decay rates, thresholds, or measurable degradation in state coherence over time under known perturbations. The proposed metric for a minimum time interval between inputs to observe memory decay is not supported by any temporal or degradation-based data in the available evidence. Thus, no basis exists to define such a threshold in the current dataset. This confirms the absence of required temporal anchors for evaluating memory persistence in tokenized agents as per the research objective.
