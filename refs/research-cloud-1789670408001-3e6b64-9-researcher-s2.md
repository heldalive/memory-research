# Revoked but Still Authoritative: An Empirical Study of Revocation Enforcement in Agent-Memory Systems

[Source](https://arxiv.org/abs/2609.08258v1)

abstract only.

The reviewed sources [S1] and [S2] do not describe a controlled memory retention experiment under token-constrained conditions with explicit baseline reporting or measurable state evolution. [S1] proposes MRMMIA to detect membership in chat agent memory through multi-recall probes, highlighting privacy risks but not evaluating retention under token budgeting. [S2] evaluates revocation enforcement and finds no system enforces revocation by default, yet does not report memory retention or state evolution under token constraints. Neither study meets the required criteria for a controlled, token-constrained evaluation of memory retention with baseline comparisons and observable state changes.
